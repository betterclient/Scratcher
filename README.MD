# Scratcher
Scratcher is a high level programming language that compiles to scratch.

It brings high level features such as lambdas, generics, closures, garbage collection, null safety while also being heavily optimized.

## Learn scratcher
Scratcher has documentation! Start by making a [hello world](docs/hello_world.md) app!

Or if you're already experienced and want to learn quickly, look at the [cheat sheet](docs/cheatsheet.md)!
